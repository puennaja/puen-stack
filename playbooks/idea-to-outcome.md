# Pilot Quickstart (Tooling Guide)

The canonical workflow has moved to [puen-engineer](https://github.com/puennaja/puen-engineer/blob/master/playbooks/idea-to-outcome.md).

1. Read the canonical playbook.
2. Run `npm run setup` in puen-stack to select agents/providers and install skills.
3. Follow the selected agent and tracker provider setup guides.
4. Respect human gates and record real evidence and failures under product repository `docs/pilot/`.

This is a tooling quickstart, not a second workflow source of truth.
